## 3. 电源结构（详见 01_system_block.png）

- **充电**：USB-C → 板载 ETA9640P → 电池（J0100）
- **系统供电**：电池 VSYS → 板载 buck/LDO → 主板 + 屏
- **4G 供电**：电池 → **升压 3.7→5V ≥2A** → 470µF/100nF → 4G 板 5V/G
- **地**：电池、开发板、4G 全部共地（GND 单点汇合，线要短粗）

## 6. 装配步骤

1. 电池改 PH2.0 插头 → 接 J0100（红+/黑−）；先**只接电池**开机验证（不插 USB）。
2. 插 USB-C 验证板载充电（看充电灯/电池电压上升）。
3. 电池接升压模块，输出调到 5.0V；在 4G 板的 5V/G 处并 470µF+100nF。
4. 接 4G 5V/G → PWR 灯应亮；接 PK↔G 自启 → NET 灯闪。
5. 接 UART 三线（TX→pin10，G→pin9；RX 待电平确认后再接）。
6. 接 4G 天线（RF1）、插已解除 PIN 的 SIM。
7. 用固件命令 `cellmon -t 10` / `cell_at AT` 验证串口（详见 43 号文 §二十）。
8. 装入外壳：电池固定 → 主板/屏 → 4G 与天线净空 → 升压模块与电容 → 开孔对齐（USB-C、SIM、按键）→ 合壳。

## 8. 风险与备选

- **4G UART 电平未知**：若 1.8V → 用 TXS0102 / 把 io_sel 拉低到 GND。
- **4G 5V 峰值 2A**：升压选 ≥2A、线短粗、470µF 就近；否则会掉压重启。
- **天线**：金属外壳/电池会严重恶化信号 → 天线区域用塑料，净空 ≥8mm。
- **发热**：4G 发射发热，别把 4G 板紧贴电池；外壳留散热孔或金属片。
- **电池安全**：确认电池自带保护板；装壳前用热缩管包焊点，防短路。

## 9. 充电/保护模块（TP4056）到底还要不要？——结论与电流校验

### 结论
- **充电：不需要 TP4056**。开发板已有 ETA9640P（USB-C 输入）负责给电池充电；两套充电电路不能同时接电池（会互相干扰/倒灌）。
- **保护：必须有**，但不是必须用 TP4056：
  1. 先确认 1000mAh 电池**自带保护板**（软包电池通常有；看电池上有没有小 PCB/加厚端）；
  2. 若没有保护板 → 加一块 **1S 锂电池保护板（建议 5A 规格）**；
  3. 若想复用 TP4056 模块：只接 **电池 B+/B−、负载 OUT+/OUT−**，**不要插它的 USB-C 充电口**（充电功能闲置），把它当保护板用。

### 关键：电流校验（决定保护板规格 / 是否两块电池）
- 4G 峰值：2A @ 5V = 10W；升压效率 ~85% → 电池侧约 **3.2A**；
- 手表系统：约 0.1–0.2A；
- 合计电池侧峰值约 **3.3–3.5A**（持续时间 ~百 µs~ms 级；但 4G 连接/发射 burst 可到 10ms 级）。
- 常见 DW01+8205A（TP4056 模块上的保护）过流点约 **3A / 160ms 延时** → **可能被 4G 峰值触发**，表现为整机突然断电重启。
- 建议：
  - 选 **过流点 ≥5A 的 1S 保护板**；或
  - **4G 单独一块小电池**（各自保护，最稳）；或
  - 用 470–1000µF + 短粗线缓冲，但 10ms 级 burst 仍主要靠电池/保护板余量。

### 对外壳布局的影响
- 若单电池方案：保护板放在电池旁，4G 供电线从保护板输出端取（线要短粗）；
- 若双电池方案：外壳需为第二块小电池（如 3.7V 300–500mAh）预留位置，见布局备选。

## 11. 电池怎么充电？（不用 TP4056 也一样能充）

电池的充电电路**已经集成在开发板上**，不需要外接 TP4056：

```
USB-C（开发板自带口）
   │
   ▼
ETA9640P（板载充电 IC，原理图中 U0101）
   │  充电电流由板载 Rset 电阻决定（Icharge = 1000/Rset A）
   ▼
电池（J0100，PH2.0 2 针）
```

- 电池接 J0100 后，**插开发板的 USB-C 就会自动充电**（同一个口也用于烧录/调试）；
- 外壳设计时把 **USB-C 口开在外面**即可；
- 充电指示：板上有充电 LED（原理图里的 LED/绿灯网络）；
- 充电电流：需要时可以查 Rset 阻值确认（1000mAh 电池建议 0.5–1C，即 500mA–1A）；
- **保护**是另一件事：充电 IC 不等于电池保护板，电池过放/过流保护仍要由电池自带保护板或外加 1S 保护板负责。

> 若确实想用 TP4056 的 USB-C 当充电口（例如外壳开孔位置更好），那就只保留 TP4056 的充电口、**不要同时插开发板 USB-C 充电**（两者不能同时给同一电池充电）；但不推荐，多一套电路反而增加风险。
